# esp32-laptop-power-controller

基于 ESP32 与 Python 云端中枢的物理远程开机方案。通过舵机物理按压电脑电源键实现开关机，解决无公网 IP 及网络唤醒（WoL）不可用的场景。

## 项目组成与用途

本项目由两部分组成：

### 1. ESP32 固件 (src/ / include/)
运行在内网的 ESP32 开发板上。主要用途是驱动舵机（如 SG90、MG90S）模拟手指机械按压电脑电源键。采用反向 HTTP 轮询模式，定时主动向云端服务器请求是否有开机任务，无需配置内网穿透或常开中继设备。支持 AP 模式配网和在网页端在线微调舵机角度。

### 2. 云端控制服务 (server.py)
运行在公网服务器上的轻量 Python 服务（仅使用标准库，无需安装依赖）。主要用途是提供一个带身份认证的 Web 控制页面，供用户在手机或电脑浏览器中点击按钮触发开机任务；同时提供命令接口，供内网的 ESP32 定时拉取指令执行。
