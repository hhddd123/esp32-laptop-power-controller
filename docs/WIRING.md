# 坨机机械按压接线建议

当前方案已确定：坨机 = 机械按压笔记本电源键。也就是说 ESP32 不直接碰笔记本主板电路，而是输出 PWM 信号控制坨机/舵机，让它像手指一样按一下电源键。

代码默认执行器：

- 类型：servo
- 信号 GPIO：17
- 待机角度：30°
- 按下角度：128°
- 按压时间：900ms

这些参数都可以在 Web 配置页修改。

## 推荐接线

```text
ESP32 GPIO17       -> 坨机/舵机 信号线
独立 5V 电源 +     -> 坨机/舵机 VCC
独立 5V 电源 -     -> 坨机/舵机 GND
ESP32 GND          -> 坨机/舵机 GND，也就是和独立 5V 电源负极共地
```

如果你的坨机不是普通三线舵机，而是带驱动板/控制器的机械按压模块，请优先按模块说明书接线。常见可能是：

- PWM 舵机输入：接 ESP32 GPIO17
- 高低电平触发输入：改用 relay/GPIO 模式更合适
- UART/I2C 控制：需要后续按模块协议改代码

## 调试顺序

1. 先不要让坨机对准笔记本电源键。
2. 给 ESP32 和坨机供电。
3. 打开 ESP32 Web 页面，进入配置页。
4. 小幅调整待机角度和按下角度。
5. 确认坨机动作方向、力度、回弹都正常。
6. 再固定到笔记本电源键位置。
7. 最后再测试真实按键触发。

## 机械固定注意

- 待机角度必须完全离开电源键，不能长期压住。
- 按下角度只需要刚好触发，不要过度用力。
- 固定架要防滑，避免长期使用后位置漂移。
- 建议给坨机留一点缓冲，比如软胶垫，避免硬顶笔记本按键。
- 如果电源键很薄或很脆，优先降低角度和按压时间。

## 供电注意

- 不建议从 ESP32 3.3V 给坨机/舵机供电。
- 小舵机启动电流可能让 ESP32 掉电重启，建议独立 5V 供电。
- 独立 5V 电源的 GND 必须和 ESP32 GND 共地，否则 PWM 信号没有参考地。
- 如果动作时 ESP32 重启，优先怀疑供电不足或共地不好。

## 备用方案：继电器/光耦短接

代码仍保留继电器/光耦短接笔记本电源键的备用模式，但当前不作为默认方案。

备用默认参数：

- GPIO：26
- 有效电平：高电平
- 脉冲：700ms

只有在你以后决定拆机并联电源键两端时，才需要考虑这个方案。

## 长按/短按

当前默认是短按 900ms，适合开机/睡眠唤醒。强制关机通常需要长按 4~8 秒，建议以后单独做一个“长按”接口，并在 Web 页面加二次确认，避免误关机。
