# 安全建议

这个项目可以远程按下笔记本电源键，因此需要按“高风险控制接口”处理。

## 必做

1. 首次配置后立刻修改 Web 管理密码。
2. frp token 使用长随机字符串。
3. 不要把默认 `admin123456` 暴露到公网。
4. 服务器安全组/防火墙限制访问来源 IP。
5. 推荐在服务器前面加 HTTPS 反向代理。

## 推荐访问方式

安全性从高到低大致是：

1. WireGuard/Tailscale/ZeroTier 等 VPN 后访问 ESP32。
2. frp 只监听服务器 localhost，再由 Nginx/Caddy 做 HTTPS + 强鉴权。
3. frp 直接暴露 TCP/HTTP，但限制来源 IP，并使用强密码。
4. 直接公网裸露 ESP32 Web 页面：不推荐。

## Web 认证

当前固件使用 HTTP Basic Auth：

- 用户名：`admin`
- 密码：Web 配置页修改

Basic Auth 如果走纯 HTTP，密码会被明文传输。因此外网访问建议通过 HTTPS 反代。

## 误触发风险

当前 `/api/power/press` 会短按电源键。浏览器页面有确认弹窗，但 API 直接调用不会二次确认。

后续如果增加“长按强制关机”，建议：

- 单独接口
- 更长确认流程
- 可选一次性 token
- 操作日志

## 硬件安全

- 推荐光耦/继电器隔离。
- 不要让 ESP32 GPIO 直接接主板未知脚位。
- 舵机使用独立 5V 电源，并与 ESP32 共地。
- 固定执行器，避免卡住电源键导致长按关机或硬件损坏。
